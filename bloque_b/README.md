| Documento | Contenido |
|---|---|
| `Requerimientos Funcionales  y No Funcionales.docx.pdf` | 50 requerimientos funcionales y 36 no funcionales, clasificados por componente (web, microservicios, móvil, escritorio, infraestructura, seguridad, monitoreo) |

| `Matriz de Trazabilidad.docx.pdf` | Requisito → historia de usuario → caso de uso → componente que lo implementa |
